# Architecture decision records

本目錄保存會長期影響模組 seam、資料、安全、部署或治理的決策。

命名格式：`NNNN-short-kebab-title.md`。

每份 ADR 包含：Status、Date、Context、Decision、Consequences、Rejected alternatives。Accepted ADR 不直接重寫結論；若方向改變，新增 ADR 並標示 `Supersedes ADR-NNNN`。小型、局部、可逆 implementation 變更不需要 ADR。
