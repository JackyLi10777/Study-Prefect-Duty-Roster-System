# ADR-0002: 日期席位核心與不可變發布版本

- **Status:** Accepted for prelaunch implementation; not implemented or deployed by this record
- **Date:** 2026-09-05

## Context

[正式啟用計劃](../plans/20260905-system-integration.md)允許新正式空庫及模型重構。現有房號身份、固定六行與星期持久化不能完整表達年度房間變更、可調人數及跨週 CP 日期活動。正式與 Guest 重複實作規則，也增加輸出和報告失同步的機會。

## Decision

採普通操作優先的意圖式 Interface：普通與 CP 分別接收清楚的生成 request，正規化成共用的日期席位模型；候選、編輯、發布、更正、撤回及報告只保留一套業務 Implementation。UI 不負責日期展開、政策選版或交易機制；寫入仍有明確 command identity 及版本前提，不採任意字串操作加無型別 payload。

業務崗位使用穩定身份，房間是可修改資料。學年政策修訂與有效政策快照分開；發布時保存完整版本及每席整數服務分鐘。更正新增版本並原子切換有效版本，不能原地改寫舊發布安排。報告由有效發布席位按實際日期聚合，不另設分鐘事件帳或背景投影；普通公平與 CP 公平排序分開，均不代替服務時數。

純規則、編排及呈現保持 in-process。只在原子儲存 Seam 使用兩個真 Adapter：Official SQLite 與隔離 Guest memory。共用業務規則，Adapter 承擔交易／revision 檢查、收據及各自容許的持久化能力；Guest 不偽裝正式備份或分享。SQLite 可用可核對、可重建的當前日期占位表和唯一約束防止跨模式並行雙重發布；它不是另一套排班或時數權威。

頁面、PDF、PNG 及分享消費同一次一致讀取的排班呈現；正式分鐘來自發布快照，不從現行時間常數或顯示文字重算。渲染不持有資料庫讀交易。保留提交、備份待補、分享撤銷的不同狀態，已提交但備份失敗不得提示使用者重新生成業務。

## Consequences

- 下一任維護者只需理解普通／CP 的輸入差异和共同生命週期；[領域詞彙](../../CONTEXT.md)統一名稱。
- 新正式庫不匯入演練排班。新核心切換前保留現行可運行版本；切換通過後移除被取代的固定模型及重複規則，不保留永久 legacy Adapter。
- 普通人數擴容與完整動態 PDF／雙 PNG 一起驗收，不能先開放20行設定卻只匯出六行。CP 在日期限制、全期操作、分頁輸出及報告閉環一併完成後才啟用。
- 政策欄位採正規化儲存或經嚴格驗證的版本化文件，須由實作契約測試比較後確定；本決策不提前固定尚未驗證的表名或序列化形狀，也不容許兩套可修改設定來源。

## Rejected alternatives

- **只延伸房號 enum 及固定週表**：無法讓 CP 的非連續實際日期、可調房間／席位自然共用規則。
- **普通與 CP 各複製一套 workflow**：資格、交易、報告及 Guest 會再度出現多份權威。
- **僅以三個通用方法為目標**：方法少不等於 Interface 容易理解；大量異構操作仍會推高常用 caller 的認知負擔。
- **新增完整 event-sourcing／分鐘帳本／遠端服務**：本輪沒有需要重播事件或跨網路計算的需求；有效發布快照已足以準確計算報告。

## Implementation checkpoint — pure policy preparation

`packages/roster_policy/roster_policy/configurable.py` 提供未接入現行 runtime 的純政策編譯器：
普通／CP 意圖輸入共用日期席位展開、不可變設定、20 行上限及整數時段。
它不生成當值人員、不持久化設定、不初始化正式庫，也不計算已編排服務總數。
`tests/test_configurable_roster_policy.py` 的 74 個案例涵蓋預設／自訂時段、房間、
F1 開關、日期例外、最大列數及輸入隔離；與既有規則、文件、治理測試合計 144 項通過。
此檢查不是完整 C 階段、正式 release 或部署驗收。

接入共同操作 Module 前，仍必須完成：

- 學年設定修訂、明確採用政策及不可變發布儲存；不能以瀏覽器快取代替持久設定。
- `ApprovedUnavailable` 的核准引用由 workflow 核實並在發布交易保存；
  純編譯器只驗證其存在，不能把任意輸入字串當成老師授權。
- 呈現席位不暴露核准引用，但內部發布證據不可丟棄。
- `service_minutes` 在關閉列仍表示時段長度；報告只合計有效發布且實際指派的席位，
  不能直接加總所有編譯列。
- 與人物資格、同日防重複、完整動態輸出及 Official／Guest Adapter 一起驗證後才切換使用。
