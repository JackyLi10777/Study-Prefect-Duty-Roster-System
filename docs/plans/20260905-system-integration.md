# 正式啟用版：整體重構與剩餘工作執行計劃

## 已批准前提

本文件取代原先的歷史資料遷移方案。使用者於 2026-09-05 明確確認系統尚未正式啟用，
允許核心／資料模型重構，正式使用全新空庫。舊演練資料不進正式年報，不為它增加相容層；
不自動刪除舊資料或更動原始未提交工作區。現有技術棧、權限隔離與恢復保障保留。
「最終形態」是以下需求全部驗收後可投入使用，不是假定永遠不用演進。

實作狀態與來源記錄由 [需求追蹤表](PRELAUNCH_DELIVERY.md) 擁有。
[審查記錄](../audits/20260905-parallel-integration-review.md) 是當時來源的缺陷清單，
後續修正要重新核對，不當成最新版必然存在的問題。
[目前部署記錄](../status/CURRENT_STATUS.md) 只證明所記錄的技術部署，不證明學校已正式啟用。

## 目標架構

學年設定 → 有效規則快照 → 普通／CP 排班 → 版本化發布結果 → 頁面、PDF、PNG、分享、年報。

- 設定模組擁有學年、預設值、房間、人數、開放狀態、星期及時間。
- 排班模組共用日期與席位，普通／CP 使用不同角色與可用日期規則。
- 操作模組統一版本、command_id、交易、備份義務、收據及恢復。
- 呈現模組只讀一次原子快照，各輸出不得各自查庫或重算時間。
- 報告模組從有效發布結果計算整數分鐘；公平分與服務分鐘分開。
- 交付模組擁有 PDF／PNG、預覽、一次性下載及原生分享生命週期。
- 新內部資料概念：學年政策修訂、有效政策快照、排班模式、實際日期席位、發布版本、服务分鐘來源。
- Official／Guest 共用規則及 presentation、分開持久化與虛構隔離儲存。UI 不直接存取 SQLite。
- 建立正式啟用 schema 與空庫初始化；啟用後從此基線承擔版本遷移。
- 保留 Python、NiceGUI／Quasar、SQLite／Alembic、Pillow、Material、WebAudio、GSAP；
  不增加前端框架、圖示家族或音頻資源包。

## CP Test Revision

- 在 /rosters 內選普通／CP，不加第四項手機主導航。
- 一次設定起止日及明確勾選的實際值班日；可跨週、不固定年度日期。
- F1／F2／F3 各預設兩人，房間、人數可改，總席位 ≤20。
  往年 402／403／404 只作參考，發布前確認實際房間。
- 預設 08:55–12:00＝185 分鐘，可改。Head／Assistant Head／Study Prefect 同權安排；
  普通排班角色限制不改。
- 不可當值使用具體年月日，不沿用平日星期限制；停用人員不可選。
- 同人同日不可重複，跨普通／CP 亦檢查；草稿指出衝突，發布阻止。
- 一次生成全期，不足人手明確留空，不違規補人。草稿可空缺；
  發布前填妥或老師明確核准不可用席位。
- CP 公平按 CP 分鐘及次數，與普通公平分開；避免連續日為次要偏好。
- 完成設定→不可用日期→生成→編輯→發布→調整／恢復／撤回→匯出→年報。
- 日視圖、完整 PDF、每頁最多十個實際日期的詳表 PNG；首版不使用 Public Viewer
  或普通週表頭像版式。

## 報告與匯出

- 報告按任意起止日期統計有效發布結果，不限星期一；列普通、CP、合計及來源。
- 普通／CP 預設 80／185 分鐘；自訂時段依該次不可變發布快照，不讀現行全域設定。
- 整數分鐘累加，只在輸出格式化小時／分鐘。草稿、撤回、關閉、空缺及被替換安排不計。
- 重送、恢復及調整不重複計數；公平 PDF 同樣使用單次一致交易快照。
- 報告標示「已編排服務時數」，人工核對／簽署後才能作完成服務證明；不新增出席系統。
- 舊資料不進新正式庫，取消歷史回填；保留演練報告的普通記錄按 80 分鐘。
- 普通 Avatar 1024×1024、Detail 1600×2000，均不透明 RGB、≤5MiB、無 metadata。
  中央圓裁安全區保留完整姓名、正式英文崗位、每行時間、星期／日期、狀態、版本。
  中文姓名最多兩行；48px 縮圖文字可讀性不是失敗條件。
- 預設六行／30格及最大二十行／100格都要逐格比對；允許設定必須能完整匯出，不截斷／漏行。
- Published 頁面優先生成並下載頭像；另選詳表、PDF、繁中／英文，姓名保持中文。
- 檔名 SYSS_Roster_YYYYMMDD_vN_Avatar_ZH.png／WhatsApp_ZH.png；英文 EN，Guest PRACTICE_ 前綴。
- Published Admin 才能派發；draft 只預覽；Guest 強制中央 PRACTICE、可下載不可原生分享；
  withdrawn 不派發。vN+1 收據提示旧 PDF／PNG 過期，重新發圖及手動換 WhatsApp 頭像。
- 不由 PDF 截圖、不上傳第三方、不代操作 WhatsApp。兩種格式使用同一原子快照。
- 90秒、session＋mode綁定、單次消費、POST ticket-in-body、no-store、nosniff、精確 MIME；
  原生分享 allowlist 只有 PDF／PNG，渲染並發總共2／Guest1。
- 關閉／換選項／重生成／登出清理舊預覽、Blob及handler；不記錄 payload、token或session。

## 手機與低負載

- Dashboard／Public：用途、狀態、主要下一步；More 先導航後偏好。
- 草稿：日視圖、常駐 sheet／保存 Dock、局部更新、候選懶載入；調整不預選岗位或空缺。
- 名冊：常駐搜尋、篩選摘要、每批≤20、單人編輯sheet；
  匯入來源→映射→預覽→提交，保存失敗不繼續匯入。
- Audit 先異常；Handover 先下一步；Settings 偏好／恢復分區；Access 先身份與安全；
  Support 先三項必填。內容頁單列按需展開，Viewer 手機按日／打印完整表格。
- 全頁共用按鈕／狀態／焦點／確認／收據。成功依持久化結果，不等待動畫，不縮短危險確認。
- 瀏覽器只處理已授權已載入資料的搜尋排序、切日、表單試算、局部更新及Viewer解密。
  全域查詢、資格、排班、交易、報告、確定性匯出及備份由伺服器擁有。
- 本地二十人不是全名冊；正式敏感資料不預設寫持久瀏覽器cache。
- 隱藏頁停止一般輪詢，返回即核對；到期、撤權、伺服器權限持續生效。
- 下載 registry 共用最近到期 one-shot cleanup，無流量仍釋放到期內容，空時零清理timer。
- GSAP 按需／空閒載入，移除boot polling、縮小observer。音效／音樂預設關；
  首次主動播放前音頻0B，已保存偏好保留。
- 伺服器及手機同時量測，運算搬移不等於總能耗降低。

## 驗收與正式啟用

- 普通80／CP185與自訂時段、各狀態／語言／姓名、最大席位、多頁CP、跨模式重複、
  網路重試、版本衝突、備份義務、下載及分享取消均覆蓋；只用虛構姓名。
- 保留Admin／Guest／Public／Viewer隔離及fragment密鑰只在瀏覽器的契約。
- Chromium／WebKit：256px reflow、320×760、360×800、390×844、430×932、
  844×390、768×1024、820×1180；中英、深淺、200%字、reduced-motion、
  forced-colors、软鍵盤／橫屏；溢出0、觸控≥44px、輸入字≥16px。
- 390×844、DPR2、Fast4G、4×CPU，每項至少5次p75：

| 指標 | NiceGUI | Public／Viewer |
|---|---:|---:|
| TTFB | ≤800ms | ≤500ms |
| FCP／LCP | ≤1.8s／2.5s | ≤1.5s／2.0s |
| CLS | ≤0.05 | ≤0.05 |
| TBT／最長任務 | ≤300ms／200ms | ≤200ms／150ms |

| 冷首屏資源／請求 | ≤2MiB／80 | ≤350KiB／10 |

- 核心操作不新增>50ms任務；20次dialog循環heap增量≤10MiB、DOM≤100、listener≤40。
  未展開不掛載；無瀏覽器／可見／隱藏／多分頁量測request、CPU、heap與timer。
- Public／Viewer gate必須正式執行，證據不隨臨時workspace刪除，不提高預算掩蓋失敗。
- pre-push、治理、test-and-audit／analyze通過後合併；乾淨確切main執行 --release，
  分支報告不能冒充merge報告。
- 核對host／readyz／schema／verified backup／Worker，有差異先對帳。不可變bundle切換；
  Worker有變更才0%candidate再升流量。保留相容恢復，不只回退程式碼。
- 全新正式庫只匯入操作者核對的名冊，演練排班與公平資料不混入。
- 實體Android／iPhone Safari、批准WhatsApp群下載／換圖／分享／更新、
  一次受監督加密備份恢復全部通過才更新啟用狀態。
- 交付操作手冊、年度交接、恢復程序與需求驗收矩陣；未完成的人工作業明確列出。
