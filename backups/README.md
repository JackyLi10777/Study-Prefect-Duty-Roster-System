# backups/ 資料夾使用說明

此資料夾用於長期保存系統的**動態數據備份**（JSON 格式），提供版本控制與災難恢復能力。

## 為什麼需要這個資料夾？

- Streamlit Cloud 為無狀態環境，休眠或重新部署後資料可能遺失。
- JSON 備份是動態數據（累計點數、當週排班、手動調整等）的主要保存方式。
- 將備份上傳至 GitHub，可實現長期版本管理與跨裝置還原。

## 使用方式

### 1. 下載備份
- 在網頁側邊欄點擊「立即備份」或相關下載按鈕，下載 JSON 檔案。

### 2. 上傳至 GitHub
1. 將下載的 JSON 檔案重新命名（建議格式）：
   - `backup_2026-06-13_週三.json`
   - `backup_期中考前_2026-06-20.json`
   - `backup_重要版本_2026-06-25.json`
2. 上傳至此 `backups/` 資料夾。
3. 撰寫有意義的 commit message 後推送，例如：
   > `backup: 2026-06-13 週三排班 + 手動調整後版本`

### 3. 還原備份
1. 從此資料夾下載對應的 JSON 備份檔案。
2. 在網頁側邊欄使用「上傳備份 JSON 還原」功能。
3. 建議優先使用「Smart Merge」模式（可保留較新的靜態資料）。

## 注意事項

- 請勿將包含敏感資訊的備份上傳至公開倉庫。
- 建議保留最近 5~10 個重要版本即可，過舊版本可刪除。
- 靜態資料（學生名冊、職位、可用日子等）請直接維護 GitHub 上的 `data/` 資料夾。
- PDF 最後一頁的備份數據僅作為緊急備援，發群前務必移除。

## 備份策略建議

| 情境               | 建議動作                                      |
|--------------------|-----------------------------------------------|
| 日常生成排班       | 下載 JSON 備份                                |
| 重要調整後         | 下載 JSON 並上傳至 `backups/`                 |
| 期中/期末前後      | 建立帶日期的版本備份並 commit                 |
| 忘記下載 JSON      | 可嘗試從當次匯出的 PDF 最後一頁還原           |

- **助理首席導學風紀**（Assistant Head Study Prefect (首席導學風紀)）
