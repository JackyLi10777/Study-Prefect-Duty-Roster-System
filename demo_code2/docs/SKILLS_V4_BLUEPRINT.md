# Skills System v4.0 Upgrade Blueprint

**Version**: v4.0 (Thinking Partner Edition)
**Date**: 2026-07-01
**Core Philosophy**: Beyond the Faster Horse + JTBD + ODI + Multi-Level Solutions

## 1. Upgrade Goals

| Dimension | Old Goal | New Goal (v4.0) |
|-----------|----------|-----------------|
| Single Skill | Execute explicit tasks | Discover deep needs + better problem definitions |
| Skill System | Tool collection | Thinking partner ecosystem |
| User Interaction | Respond to what user says | Explore why user says it + offer L1/L2/L3 options |
| Long-term Value | Complete current work | Knowledge inheritance + system anti-fragility |

## 2. Skill Categories & Priority

| Category | Priority | Representative Skills |
|----------|----------|----------------------|
| Strategic Thinking | P0 | design, grill-me, decision-mapping, shaping |
| Architecture & Systems | P0 | project-structure-advisor, codebase-design, domain-modeling |
| Quality & Diagnosis | P1 | diagnosing-bugs, code-review, check-work |
| Execution & Delivery | P2 | implement, execute-plan, prototype, handoff |
| Support & Tools | P3 | All remaining ~130 skills |

## 3. Rollout Phases

| Phase | Scope | Skills |
|-------|-------|--------|
| Phase 1 (Immediate) | Core strategy skills | design, grill-me, decision-mapping, diagnosing-bugs, skill-creator, project-structure-advisor, code-review |
| Phase 2 (Next) | High-impact skills | All sing-yin-*, implement, review, execute-plan, prototype, handoff |
| Phase 3 (Scale) | Remaining skills | All ~130 skills with lightweight Deep-Need block |

## 4. Success Metrics

- Did the user gain a better problem definition they did not initially have?
- Are L2 or L3 level suggestions being proactively offered?
- Do produced artifacts better support knowledge inheritance?
